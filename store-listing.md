# Chrome Web Store Listing (copy and paste)

## Store listing tab

**Category:** Productivity → Tools

**Language:** English (United States)

**Detailed description:**

```
Markback lets you save the best moments of any YouTube video or Short and jump right back to them.

Click the bookmark button in the YouTube player to save the current timestamp. Open the extension to see every bookmark for the video you're watching, then play from any of them with one click.

FEATURES
• Bookmark any moment in YouTube videos and Shorts with one click.
• Add a note to each bookmark.
• See a preview frame of the video at each bookmark.
• A progress bar shows how close the video is to your next bookmark.
• Optionally split the video into parts at your bookmarks, shown in the player's time display.
• See every video you've bookmarked, sorted by most recently updated or by number of bookmarks.
• Export all your bookmarks to a file and import them again on another computer.
• Works with the keyboard and screen readers.

PRIVACY
Your bookmarks are saved in your own Chrome storage and synced with your Chrome profile. Nothing is collected or sent to anyone else.

This extension is not affiliated with or endorsed by YouTube or Google.
```

## Privacy tab

**Single purpose:**

```
Save timestamped bookmarks (with optional notes) on YouTube videos and Shorts, and jump back to them later.
```

**Permission justification: storage**

```
Used to save the user's bookmarks, notes, and settings in chrome.storage.sync so they persist and sync across the user's own Chrome profile.
```

**Permission justification: host permission (`https://*.youtube.com/*`)**

```
Needed to add the bookmark button to the YouTube player, read the current video's time and title when the user saves a bookmark, jump to a bookmark's time, capture preview frames of the video at each bookmark, and know which video the user is on when the popup is opened. The extension only runs on YouTube.
```

**Are you using remote code?** No, I am not using remote code.

**Data usage:** check none of the data types (the extension does not collect or transmit any user data; everything stays in the user's own Chrome storage).

Then check all three certifications:

- I do not sell or transfer user data to third parties, outside of the approved use cases.
- I do not use or transfer user data for purposes that are unrelated to my item's single purpose.
- I do not use or transfer user data to determine creditworthiness or for lending purposes.
